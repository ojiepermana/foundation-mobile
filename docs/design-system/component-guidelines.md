# Native components

Build a screen with SwiftUI or Compose controls and apply the semantic tokens to shared visual decisions. Preserve intrinsic size, wrapping, system interaction feedback, focus and accessibility semantics. Use platform controls for future navigation and inputs.

The greeting needs a single text element. Introduce a reusable native component when concrete screens need the same behavior and lifecycle. If both apps share its identity, agree on token roles first and give each platform ownership of its implementation.
